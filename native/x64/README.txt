このフォルダの次の3つの DLL（x64 版）は、リポジトリに含めています。ビルド時に出力フォルダへコピーされます。
  libwebp.dll / libwebpdemux.dll / libsharpyuv.dll
3つはセットです。入れ替えるときは必ず3つまとめて置いてください。
1つでも欠けると連鎖して読み込めなくなり、エラーは出ずに「DLL なし」と同じ動きになります
（WebPはOSの拡張機能頼みになり、アニメーションWebPは1コマ目だけ表示されます）。
libwebp は BSD ライセンスです。DLL を含めて配布するときはライセンス文（COPYING）も一緒に入れてください。
詳しくはリポジトリ直下の README.md を参照。
